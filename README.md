# 自动关机与远程控制

一套运行在 Windows 上的定时关机 / 远程关机工具。

> **定位：** 这是一套**设备所有者本人知情、同意、可随时撤回**的自我约束工具。它帮助使用者在约定的时间停止使用电脑，或让被授权的协助者在同一局域网内提前关机。
>
> 它**不是**戒除网瘾的医疗手段，也**不是**用来管控他人设备的工具。

---

## 使用场景：帮助室友减少网游时间

典型用法：室友自己希望减少游戏时间，主动请求你帮忙。他在这台电脑上装好工具，把访问令牌交给你；到点电脑自动关机，或者你在他同意的时间段内从手机/另一台电脑帮他关掉。

让这种做法成立的几个前提：

| 前提 | 说明 |
| --- | --- |
| 本人知情 | 电脑所有者知道装了什么、在哪里、怎么卸 |
| 本人同意 | 是他请求的帮助，不是被强加的管教 |
| 可随时撤回 | 他随时可以自己暂停或卸载，你无法阻止 |
| 不隐蔽 | 不做隐藏安装、不隐藏进程、不改名伪装 |
| 不升级 | 出现抵触、争吵或影响正事时立刻停用 |

**如果这些前提不成立，请不要使用。** 强制关闭别人的电脑会丢失未保存的工作，也可能破坏关系；这不是这套工具能解决的问题。真正影响生活的沉迷，应该寻求专业帮助。

这套工具**有意**保留了两点：设备所有者始终能自己卸载；服务不隐藏、不做防绕过。因为自我约束的价值来自本人愿意配合，而不是来自外部强制。

---

## 能做什么，不能做什么

| 能 | 不能 |
| --- | --- |
| 每天固定时间自动关机 | 阻止他重装系统或改用手机 |
| 局域网内从浏览器提前关机、取消关机 | 监控屏幕、限制特定游戏、记录上网内容 |
| 查看目标机时间、任务状态、最近操作 | 在关机或睡眠状态下被远程唤醒 |
| 锁屏状态下仍可远程操作 | 在注销 / 登录界面状态下工作 |

## 使用方法

### 一、在目标电脑上安装（只做一次）

目标电脑 = 要被定时关机的那台。

**1. 把整个文件夹放到本机固定磁盘**

例如 `C:\nuclear_weapen`。不要放在 U 盘或移动硬盘上——开机登录时磁盘可能还没挂载，任务会失败。

**2. 修改配置**

打开 `config.bat`，只需要改这几项：

| 配置项 | 示例 | 含义 |
| --- | --- | --- |
| `TARGET_TIME` | `23:30` | 每天几点关机 |
| `LEAD_MINUTES` | `10` | 提前几分钟下发关机命令，留出取消时间（不要设 0） |
| `FORCE` | `1` | 1 = 强制关闭程序（未保存内容会丢）；0 = 正常关闭 |
| `REMOTE_PORT` | `8765` | 远程控制端口 |

建议把 `FORCE` 设成 `0`，让系统正常关闭程序，减少丢数据的风险。

**3. 安装每日关机任务**

双击 `install-task.bat`。它会创建计划任务 `AutoShutdownDaily`，每天在 `TARGET_TIME - LEAD_MINUTES` 触发。改过 `config.bat` 后要重新双击一次。

**4. 安装远程控制（可选）**

双击 `remote\install-remote.bat`，UAC 弹窗点「是」。

安装完成后窗口会打印：

```
安装完成。访问地址：
  http://<目标机IP>:8765/
令牌文件: C:\nuclear_weapen\remote\token.txt
```

记下这个地址和令牌。窗口里「服务身份」应该是 `你的电脑名\用户名`，而不是 `Everyone`。

**5. 把令牌交给协助者**

令牌就是 `remote\token.txt` 里那 32 位字符。拿到令牌的人可以在同一局域网内控制这台电脑，请只交给你信任的人。

### 二、日常使用

**控制端**（手机或另一台电脑，必须在同一局域网）：

1. 浏览器打开 `http://目标电脑IP:8765/`
   - 必须是 `http://`，不是 `https://`
   - 不要双击打开本地的 `index.html`（地址栏是 `file:///...` 时永远连不上）
2. 粘贴令牌，点「连接」。浏览器会记住，下次不用再输
3. 页面分三块：

| 区域 | 作用 |
| --- | --- |
| 状态 | 目标机时间、每日任务状态、下次自动运行时间、本次排定、最近操作。每 5 秒刷新 |
| 定时关机 | 选 `HH:MM` 排定；或点「10 / 30 / 60 分钟后」 |
| 危险操作 | 「立即关机（无法取消）」、「取消关机」、「更换令牌」 |

**点危险按钮前先看页面左上角的主机名**，确认是目标电脑，不是你自己这台。

### 三、暂停、取消、卸载

以下操作都在目标电脑上双击执行，设备所有者自己随时可以做：

| 操作 | 做法 | 效果 |
| --- | --- | --- |
| 暂停每日关机 | `toggle-task.bat` | 停用任务，并取消已排定的关机；再双击恢复 |
| 取消今天这一次 | `cancel-shutdown.bat` | 只取消当前排定的关机 |
| 删除每日任务 | `uninstall-task.bat` | 彻底移除任务 |
| 卸载远程控制 | `remote\uninstall-remote.bat` | 删除计划任务、防火墙规则、URL ACL |
| 连令牌和日志一起删 | 命令行加 `-Purge` | 见下方 |

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "remote\uninstall-remote.ps1" -Purge
```

## 安全与限制

- **立即关机不可撤销。** 页面上的「立即关机（无法取消）」执行 `shutdown /s /f /t 0`，发出后系统立刻关闭，`/f` 会强制结束程序，未保存的内容直接丢失。日常约束建议只用每日定时关机。
- **只在登录状态下工作。** 锁屏可以远程操作；注销或停在登录界面时服务不运行；睡眠 / 休眠状态不可达。
- **仅局域网。** 防火墙规则只放行 `LocalSubnet`，外网连不进来。令牌通过明文 HTTP 传输，不要在公司或公共 WiFi 使用。
- **IP 会变。** 路由器动态分配，重启后可能换地址。建议在路由器里做 DHCP 地址保留。
- **可以绕过。** 换手机、重装系统、停掉服务都能绕开。这是有意保留的——工具只服务于本人愿意配合的约束。
- **服务可能被意外终止。** 如果页面打不开，先在目标机浏览器访问 `http://127.0.0.1:8765/` 判断是服务没运行还是网络问题，再重新运行安装脚本。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 页面打不开 | 目标机本机访问 `http://127.0.0.1:8765/`；打不开就重跑 `remote\install-remote.bat` |
| 输入令牌后提示连接失败 | 确认地址是目标机 IP、端口 8765、两台机在同一网段 |
| 提示「令牌无效」（401） | 令牌属于另一台机器，或安装时生成过新令牌 |
| 页面显示「每日任务：未安装」 | 在目标机运行 `install-task.bat` |
| 安装时报 `UserId:S-1-1-0` / `Everyone` | 使用最新版安装脚本，它会用当前登录用户作为服务身份 |
| 想看服务在做什么 | `remote\server.log` |

更完整的配置说明见 [`使用说明.md`](使用说明.md)。

## 文件清单

| 路径 | 作用 |
| --- | --- |
| `config.bat` | 每日关机配置 |
| `install-task.bat` / `toggle-task.bat` / `uninstall-task.bat` | 每日任务的安装、暂停、删除 |
| `shutdown-at.bat` / `cancel-shutdown.bat` / `helper.ps1` | 执行关机、取消、时间计算 |
| `remote\remote-server.ps1` | 远程控制服务 |
| `remote\index.html` | 网页控制台 |
| `remote\install-remote.bat` / `install-remote.ps1` | 安装远程控制 |
| `remote\uninstall-remote.bat` / `uninstall-remote.ps1` | 卸载远程控制 |
| `remote\start-hidden.vbs` | 无窗口启动服务，避免服务随启动窗口关闭而退出 |
| `remote\test-remote.ps1` | 集成测试（34 项断言，`-DryRun` 模式，不会真关机） |
| `remote\token.txt` | 访问令牌（自动生成） |
| `remote\server.log` | 服务日志 |
| `remote\install-state.json` | 安装状态 |
| `remote\pending.json` | 当前网页排定的关机 |
